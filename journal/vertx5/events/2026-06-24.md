## 2026-06-24 17:22

- The backport of PR 54683 broke WithSessionOnDemandTest because Vert.x 5 removed the flat Object-keyed context.getLocal(Object) API. In Vert.x 4, both Quarkus OpenedSessionsState and Hibernate Reactive ContextualDataStorage shared one map via context.putLocal(Object, Object). In Vert.x 5, each ContextLocal.registerLocal() creates a separate slot, so sessions stored by sessionFactory.withSession() (via HR ContextualDataStorage) were invisible to Panache.getSession() (via Quarkus SESSIONS_LOCAL), and vice versa.
- Fixed by removing the separate SESSIONS_LOCAL ContextLocal and HibernateReactiveVertxServiceProvider entirely. OpenedSessionsState now stores and retrieves sessions directly via HR ContextualDataStorage with BaseKey(type, uuid), the same storage HR uses internally. This gives a single storage system with no dual lookup. ContextLocals is still used for string-keyed flags like TRANSACTIONAL_METHOD_KEY that are Quarkus-only.
- Also fixed NoEntitiesNoDatasourceTest which was getting a different error message because the code path changed.
