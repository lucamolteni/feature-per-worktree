## 2026-06-23 15:54

- Investigated CI failures on Quarkus 4.0 merge PR (quarkusio/quarkus#55020), a main-to-4.0 merge by Clement Escoffier. Julien Ponge asked for help with HR + Panache breakage.
- Downloaded CI artifacts (build-logs, test-reports-native-Data7). Found 11 failures in hibernate-reactive-panache and 6 in hibernate-reactive-panache-kotlin, all IllegalStateException: No current Mutiny.Session found. Plain HR tests (mysql, oracle, db2, mssql, mariadb) all passed.
- Root cause: merge conflict in SessionOperations.java was resolved by keeping the 4.0 version, which dropped the TRANSACTIONAL_METHOD_KEY session lookup added by my PR quarkusio/quarkus#54683. The 4.0 version used the old Key/ContextualDataStorage pattern for session storage while HibernateReactiveRecorder uses OPENED_SESSIONS_STATE, so sessions created by @Transactional were invisible to Panache.
- Fix: ported the main SessionOperations.java to Vert.x 5 APIs. Replaced Key/ContextualDataStorage/SESSION_FACTORY_MAP with OPENED_SESSIONS_STATE from HibernateReactiveRecorder, replaced context.getLocal/putLocal/removeLocal with ContextLocals.get/put/remove, added TRANSACTIONAL_METHOD_KEY fallback in getSession() and getStatelessSession(). This brought failures from 11 down to 5.
- Remaining 5 failures are all about session.currentTransaction() returning null. These tests were added by my PR #54683 and depend on an HR fix (hibernate/hibernate-reactive#3876, "[4.5] Add .currentTransaction method"). That PR was merged June 16 but HR 4.5.0.CR1 was released June 11, before the fix. No 4.5.x release since. Need Davide to cut a new HR 4.5.x release.
